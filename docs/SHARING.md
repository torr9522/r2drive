# 分享与下载

## 文件分享

公开文件同时需要 `is_public=1` 和非空 `share_token`。新上传默认公开。设为私密时清空 Token；重新公开生成新 Token，因此旧链接持续失效。

- `/public/<token>`：当前直链。
- `/public/<token>/<filename>`：历史兼容直链；文件名不参与定位。
- `/share/<token>`：元数据 HTML，下载按钮使用带文件名兼容路径。

普通网盘文件响应 `Content-Disposition: attachment`，图床文件响应 `inline`。两类文件共用 Range、统计和限额逻辑。

## 文件夹分享

网盘目录以非空 `share_token` 表示公开。`/share/folder/<token>` 将该目录作为分享根，`?folderId=` 只能进入它的后代。文件下载端点再次检查目标文件的 `folder_id` 是否在分享树内，并且只查询 `drive` 分类。

公开父目录不会改变子目录 Token；访问权限来自分享根的后代关系。文件夹分享会授权下载该分享树中的 `drive` 文件，即使单个文件自身 `is_public=0`，因为权限来自文件夹 Token。目录设私密会清除根 Token，使整个该入口失效。

移动不重新生成文件或文件夹 Token，因此独立分享 URL 保持不变。文件从某个分享文件夹树移出后，不再可通过该树的 Token 访问；移入后则按新的后代关系可见。这是动态权限结果，不是 Token 变更。

## 统计和限制

HEAD 不写统计。Range 只累计成功写出的 byte，不增加次数；完整 GET 发送完才增加次数。连接中断也会记录已写 byte。限额为累计 byte 上限，发送前检查 `used + response_length`，避免 Range 越过剩余额度。

统计写入发生在响应写出后的 `finally`。客户端读完响应后立即发起查询时可能在线程提交前抢先读取，测试应短暂轮询而不是假设同步可见。

## 兼容红线

四条公开入口和 Token 语义不得无迁移方案改变。修改分享时必须回归旧带文件名路径、HEAD、206/416、删除后 404、私密后 404、目录越界 404 和图床分类隔离。
