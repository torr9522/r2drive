## 已确认缺陷

- XHR `progress` 调用整页 `render()`，上传期间重建 `.shell`，造成滚动、焦点和交互状态风险。
- Toast 和上传完成刷新过度依赖整页重建。
- Python `cgi.FieldStorage` 在 Python 3.13 被移除。
- 文件/图床上传异常路径可能残留磁盘实体。
- 文件夹分享分类隔离不足，可能混入图床目录语义。
- Range 请求只检查“已用是否到上限”，未检查本次 Range 是否越过剩余额度。
- SQLite 缺少明确 WAL/busy timeout，并发初始化缺少写锁。
- 旧 systemd 以 root 运行；安装未使用隔离虚拟环境。
- 安装脚本的 Caddy 配置所有权不适合共享服务器。
- HTML `autofocus` 和 Modal 重建可改变移动滚动位置。

## 修复

- 上传任务保存在独立队列，进度只更新任务 DOM；Toast 只更新 Toast DOM。
- 上传完成仅刷新当前相关列表；切页不取消队列，目标目录在入队时冻结。
- 改用 `python-multipart`，增加请求体上限、单文件约束和失败清理。
- 强化网盘/图床分类条件和公开文件夹访问隔离。
- Range 在发送前检查本次字节数是否超过剩余额度。
- SQLite 启用 WAL、15 秒 busy timeout、初始化 `BEGIN IMMEDIATE`，创建会话时清理过期行。
- systemd 改用 `r2-drive` 用户、虚拟环境、`UMask=0077` 和基础 hardening。
- Caddy 站点写入独立 `sites-enabled/r2-drive.caddy`，主配置只追加 import；真实部署发现权限问题后固定为 0644。
- Modal 使用 `focus({preventScroll:true})` 并保持桌面/移动滚动容器状态。
