# 回归用例

## 排序和移动

- 根目录和多级子目录分别排序文件夹/文件；刷新、重新登录和重启后保持。
- 拖拽后立即上移/下移，两个请求顺序完成，不读旧数组。
- 搜索过滤时排序被拒绝；文件和文件夹不能混排。
- 单/批量文件、单/批量文件夹和混合选择跨层级移动；父子同选归一化。
- `cancel` / `rename` / `skip` 冲突，自身/后代循环，不存在目标和跨分类伪造。
- 移动前后 ID、Token、统计、限额、`storage_path`、HEAD、206/416 不变；分享树内容按新后代关系变化。

## 认证

- 未初始化状态只允许一次初始化；并发初始化最多一个成功。
- 错误密码 401，禁用用户 401。
- HTTPS Cookie 包含 Secure/HttpOnly/SameSite=Lax；登出使 Session 失效。

## 网盘

- 根目录和多级目录创建、进入、返回、重命名。
- 空目录可删，含文件或子目录返回 409。
- 单文件、多文件、拖拽、几十 MiB 上传。
- 上传期间滚动、搜索、切页；完成后 shell 节点不变。
- 入队后切换目录，全部文件仍进入原目标。
- 重命名不改变实体路径；删除使私有和公开入口失效。

## 图床

- JPG/JPEG/PNG/WEBP/GIF 的 MIME 与 signature 合法组合。
- SVG、伪 PNG、错误 MIME 返回 400，失败实体不残留。
- 图片/列表、预览、直链/Markdown/HTML。
- 单选、全选、批量删除、移动 root/子目录、同目录 skipped。
- 图床 ID 通过网盘 API 操作返回 404，反向同理。

## 分享和下载

- `/public/<token>` 和带任意文件名后缀的历史路径。
- `/share/<token>` 与文件夹分享后代浏览。
- 私密/删除后旧 Token 404；重新公开得到新 Token。
- HEAD 200 且统计不变。
- `bytes=2-5` 为 206，suffix Range 合法，多段/越界为 416。
- Range 只增字节，完整 GET 增次数；限额不足以覆盖本次 Range 时 403。

## 前端和移动端

- 搜索每字符输入不丢焦点、不发重复请求。
- Toast 不重建页面。
- Modal 打开/关闭桌面 `.work` 和移动 `window` 不回顶。
- 375/390/430px 无横向溢出；Drawer 和 Action Sheet 可开关。
- 上传失败有明确反馈，后续队列继续。

## 数据和部署

- v1.7 风格旧表经 `init_db()` 补字段，旧 ID/路径/行仍在。
- 服务以 `r2-drive` 用户运行，数据目录可写、其他系统路径不可写。
- 安装固定 Tag 且 `HEAD == tag^{}`。
- Caddy validate 通过，共享站点配置不变，服务重启后数据存在。
