## v1.8.3 审计主线

审计从 `v1.8.2` / `88584f5c` 建立基线，重点复现上传进度触发整页 `render()` 导致的滚动和焦点问题。核心修复 commit `aed24a2a` 将上传任务进度改为局部 DOM 更新，并同时加入 `python-multipart`、WAL/busy timeout、上传失败清理、会话清理、服务用户和安装隔离。后续提交分别处理 Caddy 配置权限、浏览器验收、Range 限额、移动 Modal 焦点及测试覆盖。

完整审计、失败案例和验收证据见 [v1.8.3 历史](history/v1.8.3.md) 与 [验收历史](testing/acceptance-history.md)。

## 研究记录

2026-10-30 曾对 Uppy Dashboard 和 Cloudreve 上传架构做有边界的参考：采用“上传状态与页面视图分离、列表局部刷新、目录状态显式化”的思路，没有引入 Uppy、前端框架或复制 Cloudreve GPL 代码。当时核实到 Uppy 相关最新发布示例为 `@uppy/vue@4.0.1`（MIT），Cloudreve 为 `4.19.1`（GPLv3）；这些是当日观察值，不代表当前最新版本。
