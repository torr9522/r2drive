# 功能与业务规则

## 我的网盘

登录后同时加载全部网盘目录、当前目录文件和网盘统计。目录导航由 `parent_id` 在前端生成面包屑；文件只加载当前目录。新文件和新网盘目录默认公开并生成 Token。

每个目录显示两个独立顺序组：文件夹始终在上，文件始终在下。桌面通过手柄拖排，移动端通过上移/下移；搜索结果不能改手动顺序。顺序保存在 SQLite，新项目追加到对应组末尾，重命名不改变位置。

上传、下载、重命名、删除、公开切换和限额分别调用对应 API。失败由统一 API 错误进入页面 alert 或 Toast；非空目录删除返回 409。文件删除后原分享 Token 立即失效。

## 我的图床

只接受 JPG/JPEG/PNG/WEBP/GIF，并同时验证扩展名、MIME 和文件头；SVG 和伪装图片拒绝。新图片默认公开，以 `inline` 方式提供。图片/列表模式保存在 `localStorage`。

图床支持预览、直链、Markdown、HTML、目录/图片选择、批量删除、排序和通用批量移动。移动不搬动磁盘实体；同目录项进入 `skipped`。单项上传失败后队列继续。

## 文件夹

网盘和图床分别允许多级目录，`root` 是虚拟根 ID，不是表中记录。创建、排序和移动目标都必须验证同用户、同分类。目录可整体跨层级移动并保留后代结构；不能移动到自身或后代。只能删除没有子目录和文件的空目录，不级联删除。

## 通用移动

网盘文件、网盘目录、图床图片和图床目录共用目标目录选择器。支持单项、同类型批量和文件/目录混合批量。父目录和后代同时选择时，后代标记为已随父目录覆盖，避免重复移动。

同名冲突默认取消整个操作，也可选择自动重命名或跳过。自动重命名使用 `name (1).ext` 形式且不会合并目录。结果明确返回成功、跳过、失败数量与首个原因。移入项目追加到目标同类型组末尾，源组压紧；被移动目录内部顺序不变。

## 搜索

只过滤当前目录已加载数据，不改变数据库、不发请求。目录切换清空搜索。上传时搜索输入和焦点必须继续可用。

## 上传

浏览器把每个文件加入串行队列，并在入队时记录 `kind` 与 `targetFolderId`。进度只更新任务区域，完成时只刷新相关当前目录。页面切换不取消任务。服务端解析单文件 multipart，写磁盘、验证（图片）、写数据库；失败清理实体。

## 下载和统计

私有下载要求 Session；公开下载要求有效 Token。普通文件为 attachment，图床为 inline。HEAD 不统计；Range 返回 206，只增加实际字节；完整 GET 完成才增加次数。无效 Range 返回 416。流量限额在发送前检查本次响应是否会超过剩余额度，超过返回 403。

## 分享

文件公开状态由 `is_public` 和 `share_token` 共同决定。设为私密会清除 Token；再次公开生成新 Token，因此旧链接不复活。文件夹公开性由非空 `folders.share_token` 表示。详细路径见 [SHARING.md](SHARING.md)。

## 反馈和移动端

确认类操作使用站内 Modal，短结果使用 Toast，移动图床次要操作使用 Action Sheet。没有业务 `alert/confirm/prompt`。375/390/430px 为移动回归基线；打开/关闭 Modal、上传和选择不得让页面回顶。
